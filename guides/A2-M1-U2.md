# A2-M1-U2 · Completed events with essere

Complete the earlier A0/A1 units and preceding A2 units before cumulative practice. This is an A2 testing sample, not a complete A2 syllabus.

## Preparation

Use present essere + the participle for the specific verbs below. The participle agrees with the subject: -o masculine singular, -a feminine singular, -i male/mixed plural, -e all-female plural. This is a list of taught verbs, not a rule that all movement verbs use essere.

- Andare → andato — go → gone
- Arrivare → arrivato — arrive → arrived
- Partire → partito — leave → left
- Tornare → tornato — come back → come back
- Rimanere → rimasto — stay → stayed
- Venire → venuto — come → come
- Svegliarsi → svegliato — wake up → woken up
- Alzarsi → alzato — get up → got up
- Vestirsi → vestito — get dressed → got dressed
- Ieri sera — yesterday evening

Sono andata a Roma: I went to Rome, a woman speaking. Siamo andati: we went, a male/mixed group. Reflexive past: mi sono svegliato/a; ti sei svegliato/a; si è svegliato/a; ci siamo svegliati/e; vi siete svegliati/e; si sono svegliati/e. Non precedes the pronoun: non mi sono alzato presto. Names and notes establish gender where it cannot be inferred.
