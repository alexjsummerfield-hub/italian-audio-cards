# A2-M1-U1 · Completed events with avere

Complete the earlier A0/A1 units and preceding A2 units before cumulative practice. This is an A2 testing sample, not a complete A2 syllabus.

## Preparation

Use the present of avere + past participle for completed events: ho, hai, ha, abbiamo, avete, hanno. The participle does not change with the subject in these cards. Put non before the auxiliary. A question keeps the same order.

- Parlare → parlato — speak → spoken
- Lavorare → lavorato — work → worked
- Studiare → studiato — study → studied
- Comprare → comprato — buy → bought
- Mangiare → mangiato — eat → eaten
- Dormire → dormito — sleep → slept
- Leggere → letto — read → read
- Scrivere → scritto — write → written
- Fare → fatto — do/make → done/made
- Prendere → preso — take → taken
- Bere → bevuto — drink → drunk
- Ieri — yesterday
- Stamattina — this morning
- La settimana scorsa — last week

Ho letto un libro means I read a book / I have read a book. Here the English prompts describe completed events. This is not a rule that every English past tense uses passato prossimo. Read the imperfetto unit before contrasting background and habitual past actions.
